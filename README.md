Senior Infrastructure and Application Engineer specializing in **AI-driven automation**, enterprise Linux systems, and cross-platform software development across **Android, Windows, and modern Web platforms**.

Bridging low-level systems engineering with application architecture, I develop intelligent automation workflows, architect high-availability private clouds (Proxmox/KVM), and deploy robust zero-trust network fabrics (pfSense, Sophos, Cloudflare). Across the software stack, I engineer native Android and Windows client applications, full-stack web platforms, and automated testing suites backed by deep production observability (Zabbix, Checkmk, Prometheus, Grafana).
