### Executive Overview

Senior Infrastructure and Operations Engineer specializing in enterprise Linux administration, multi-cloud and bare-metal infrastructure, high-availability monitoring, and zero-trust edge security. 

With deep expertise bridging low-level systems engineering and software delivery, I architect secure private cloud clusters (Proxmox/ZFS), enterprise firewall and VPN topologies (pfSense, Sophos, WireGuard), and robust observability fabrics (Zabbix, Checkmk, Prometheus, Grafana). Additionally, I engineer cross-platform client applications and automated regression test suites across Web, Windows, Android, and iOS ecosystems.
